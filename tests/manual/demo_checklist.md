# Demo Checklist

Use this quick checklist right before presenting Chronos.

- [ ] Backend and frontend both running locally
- [ ] Tasks seeded (including deadline + splittable examples)
- [ ] Availability configured for the demo week
- [ ] Protected block + max continuous work constraints added
- [ ] Schedule generated and visually conflict-free
- [ ] One valid move succeeds
- [ ] One invalid move is rejected with a clear error
- [ ] `.ics` export downloads successfully
- [ ] Smoke tests pass (`pytest`, `npm test -- --run`)

# Cross-Platform Testing

This document records how Chronos schedule export is validated across common calendar platforms.

---

## Goal

Verify that `.ics` files generated by `POST /api/schedule/export` import correctly and preserve core event fields across:

- Apple Calendar (macOS)
- Outlook (Windows desktop)
- Google Calendar (web)

---

## Automated Checks (CI + local)

Backend tests now verify:

- iCalendar envelope markers exist (`BEGIN:VCALENDAR`, `END:VCALENDAR`)
- Response headers are download-friendly (`text/calendar`, attachment filename)
- Export can be parsed by `icalendar` and contains `VEVENT` items
- Event fields required by common clients are present (`SUMMARY`, `DTSTART`, `DTEND`)
- Event metadata used by calendar clients is present (`UID`, `DTSTAMP`)
- Export uses CRLF line endings (RFC 5545 compatibility)

Run:

```bash
cd backend
pytest tests/test_schedule.py -k export_ics
```

---

## Manual Cross-Platform Import Checklist

Use the same exported file (`chronos_schedule.ics`) for each client.

### Apple Calendar (macOS)

1. Open Calendar.
2. `File -> Import...` and select `chronos_schedule.ics`.
3. Confirm events appear on expected dates/times.
4. Confirm event title matches task name.

### Outlook (Windows desktop)

1. Open Outlook Calendar.
2. `Add calendar -> Upload from file` (or `File -> Open & Export -> Import/Export` depending on version).
3. Select `chronos_schedule.ics`.
4. Confirm events import without warnings and show correct title/time.

### Google Calendar (web)

1. Open Google Calendar.
2. `Settings -> Import & export -> Import`.
3. Upload `chronos_schedule.ics`.
4. Confirm imported events show correct title/time.

---

## Pass Criteria

Week 8 is considered complete when:

- Automated export checks pass in backend tests.
- At least one successful manual import is recorded for each of Apple Calendar, Outlook, and Google Calendar.
